Describe your ex in one word. My verdict: **uninstalled** — an ex is software you removed on purpose, like a bad app you deleted and never looked back at.

`main.ts` writes the single word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), guarded so the entry is always exactly one word, 1–111 characters, with nothing else attached.
